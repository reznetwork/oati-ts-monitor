3) Interaction notes
--------------------

Selection
  • Click vehicle row label OR any activity bar → select that vehicle.
  • Main window (dashboard + map) reloads for the selected vehicle.
  • Selected row is visually highlighted.

Playhead
  • Vertical line across all rows on the shared date axis.
  • Click or drag on the timeline canvas to move playhead.
  • Dashboard shows nearest snapshot at/before playhead (slice).
  • Map playhead marker snaps to nearest wifi sample with lat/lon.

Zoom / pan
  • Mouse wheel over timeline → zoom in/out around cursor (or playhead).
  • Drag empty timeline background → pan visible date window.
  • Toolbar buttons: pan, zoom, fit-all (global min/max coverage).

Activity bars
  • Derived from uploaded segment time coverage (min/max ts per segment).
  • Contiguous / overlapping segments merged; idle gap > threshold → separate bars.
  • Gaps (no bar) mean no ingested log data for that vehicle in that interval.

Resizable regions
  • Drag vertical gutter (║) between dashboard and map.
  • Drag horizontal gutter (═) between main window and timeline.
  • Optional: drag label-column edge on timeline.
  • Splitter positions persist in browser localStorage.

|  Map: empty path or last known track in visible window                                 |
